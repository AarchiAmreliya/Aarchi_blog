Deploy to GitHub Pages

Go live in under 2 minutes directly from desktop

  1. Save File: Keep this file named index.html in a dedicated folder.
  2. Create a GitHub Repository:

    Head to GitHub.com → "New Repository" → set it to Public.

  3. Push from Terminal or Drag & Drop: 
    git init
git add index.html
git commit -m "feat: initial static blog"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
  4. Enable GitHub Pages: Go to repository Settings → Pages. Choose Source: Deploy from a branch → select main branch & / (root) → click Save.
